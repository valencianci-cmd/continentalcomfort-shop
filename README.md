# ContinentalComfort.Shop

Mobile-first e-commerce storefront for Continental HVAC, operated by Skip The Warehouse — the exclusive online distributor. Made in the Americas.

## What's here
- `public/index.html` — the full single-page store (equipment catalog, AHRI-rated system bundles, crossover finder, tiered pricing, cart). Self-contained; no build step.
- `data/` — source bundle/accessory data pulled from the STW US Pro Tool (13.4 & 14.3 SEER2).

## Deploy (Render static site)
- Publish directory: `public`
- Build command: none (static)
- Custom domain: ContinentalComfort.Shop

## Notes
Continental is Napoleon private-label: models carry the `-C` suffix; AHRI certificate numbers match the Napoleon equivalents. Pricing shown is sample/tiered for review.
